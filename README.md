# Intermezzo — сайт котеджу в Дземброні

Односторінковий сайт: `index.html` + фото в `img/`.

## Налаштування
На початку скрипту в `index.html` є блок `CONFIG`: месенджери, AI-відео, відгуки, зимові фото, плашка терміновості.

## Публікація
GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.
